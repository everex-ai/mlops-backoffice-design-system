Philosophy

3대 원칙

시맨틱 토큰 First

raw hex, slate-*, bg-white는 금지입니다. 모든 색상은 CSS 변수 기반 시맨틱 토큰으로 표현하며 라이트/다크는 변수 swap만으로 전환됩니다.

한국어 우선

Pretendard Variable을 표준으로 합니다. Inter는 채택하지 않으며 문서도 한국어 본문 + 영문 기술 용어 혼용을 따릅니다. 번역하지 않습니다.

Cross-Service 고정 스펙

헤더 49px, 로그인 split 레이아웃, Primary 173° 틸, Pretendard — 이 네 가지는 서비스 간 계약입니다. 바꾸려면 versioning 결정이 필요합니다.

Hooks · Utilities

훅 & 포맷터

세 개 이상의 서비스(video_annotator · label_supporter · AI-crawler)에서 반복적으로 나타난 유틸리티를 추출했습니다.

useKeyboardShortcuts

e.code 기반 전역 단축키 훅. 한국어 IME 상태와 무관하게 물리 키 위치로 매칭됩니다. 

useKeyboardShortcuts([
  { code: 'Space', handler: togglePlay, preventDefault: true },
  { code: 'KeyJ', handler: () => seek(-5) },
  { code: 'ArrowLeft', shift: true, handler: prevClip },
]);

useProgressStats

업로드/처리의 경과시간 · 속도 · ETA를 실시간 계산합니다. bytes / items / percent 모드.

elapsedTime · 1:24
speed · 2.4 MB/s
ETA · 약 42초

useClipboard

navigator.clipboard + 비보안 컨텍스트 폴백 + Sonner 토스트 통합. 

const { copyWithToast } = useClipboard();
copyWithToast(url, 'URL이 복사됐어요');

useDebounce · Format utils

검색 디바운스와 범용 포맷터. formatFileSize, formatETA, formatByteSpeed 등 한국어 라벨 내장.

formatFileSize(1536000) → "1.46 MB"
formatETA(45000, 5000) → "약 45초"
